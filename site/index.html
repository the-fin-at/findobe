01 / WRITE

Think in documents.

Write visually with headings, lists, images, and tables. Keep several files open in tabs. Review comments and suggestions as you go.

02 / COLLABORATE

Bring your own agent.

Give an agent access to the same local document. Revision checks and shared undo help you stay in control. Findobe includes no AI service.

03 / KEEP

Take your work with you.

Save an open .findobe working file. Import and export DOCX, ODT, HTML, Markdown, text, and PDF. Your next step is your choice.

Build from source

Install Node.js, Rust, and your platform's Tauri prerequisites, then follow the setup guide.

git clone https://github.com/the-fin-at/findobe.git
cd findobe
npm ci
npm run dev
Open the setup guide ↗

A clear picture of what's ready.

macOS: developed and tested locally on Apple Silicon. Public signing and notarization are pending.

Windows: build setup is included; the current version's runtime and installation have not yet been tested on Windows.

There is no public desktop download yet. Future packages will appear on GitHub Releases.

Document format limits

Complex Office layouts may change on import. PDF import reads the text layer; it does not reconstruct layout or perform OCR. PDF text correction is not secure redaction. Comments, suggestions, and history are fully retained only in .findobe files.
